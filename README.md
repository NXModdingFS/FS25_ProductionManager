<ins>**NX Productions**</ins> (ModHub v1.0.0.0 · Latest v1.0.0.3)

A production management mod for Farming Simulator 25: an overview of every production facility with automatic management, plus stock, profitability, animal and logistics tools in one place.

**Usage:**

Open the in-game menu (ESC) and select the **Productions Manager** tab. Use the sub-tabs along the top to switch pages; the buttons along the bottom change with each page.

<ins>**Key Features**</ins>

**Productions**

- Inputs: every production with each input's stored amount and capacity

- Outputs: one row per product with internal storage, contents already sitting in your pallets, and an estimated output per month (pallets where a pallet size is known, otherwise litres)

- Recipes: each recipe with its ingredients and status (Active / Active (!) missing inputs / Inactive)

- Finances: monthly revenue, running costs and net profit per production, valued at the best price any selling station pays (and which station that is). Output auto-delivered to another building is shown in its own "Distributed" column instead of being counted as income

- Logistics: Supply Duration, Cycles/Mo, Output Mode, Destination and Status for every recipe, with buttons to change the output mode, activate/deactivate a recipe and open its schedule

- Production Schedules: choose the months each recipe runs; productions outside their months are paused and resumed automatically. The month list marks each output's best selling month(s)

- Processing Type: See if the production supports Serial (S) or Parallel (P) processing. When the production supports Parallel processing, for every tick the server does, every active recipe advances. When the production only supports serial processing, for every tick the server does, only ONE recipe advances in turn.

- CSV Export: Export all production data for external analysis

**Insights (v1.0.0.3)**

- Stock: everything your farm owns in silos, productions, animal pens, vehicles, pallets, bales and object storage, valued at today's best price and at its best month. Open Details for where it is stored, every sell point, a month-by-month price table and which recipes earn more than selling it raw

- Price Alerts: get notified when a product reaches its best month to sell

- Profitability: every recipe from your productions, productions for sale on the map and production buildings in the shop, compared by cost, value and profit per 1000 L and per month, with payback time. Filter by owned / for sale / shop and sort per month or per 1000 L

- Animals: every animal group with age, health, value and advice (keep producing, grow to N months, sell now, restore health), plus pen supplies, feed costs and output per month

- Network: the rules for Productions Logistics (below)

- This Month: a list of what needs doing now - price alerts, best-month sales, bales left on fields, full trailers, low animal food/water/straw, low production inputs and nearly full outputs

**Productions Logistics (v1.0.0.3, optional - off by default)**

- A demand-driven supply network between your productions, animal pens and silos, run every in-game hour

- Per product rules on the Network tab: game default, hold, supply the farm, store in a silo, sell now, sell in the best month, or supply and sell the surplus. Keep a reserve in the building

- Inputs can be blocked, given a priority (low / normal / high) and a fill target

- Nearest source first, farm-wide or within a set radius; automatic feed, straw and water; transport cost per 1000 L per km; this month's activity per building

**Settings Menu**

Access settings via ESC → Settings → Game Settings. The mod adds four sections:

- Productions Manager: auto-management, hide inactive productions, notifications and their thresholds and duration

- Productions Insights (personal to each player): animal supply warning level, full trailer size, free water, price basis (current or best month) and the processing advice threshold

- Productions Logistics: network on/off, supply range, include animal pens and silos, default fill target, transport cost, automatic water and its price

- Productions: Gameplay (off by default): water has no sale value, grape and olive yield multipliers, horse / pig / beef cattle value multipliers

Productions Manager, Logistics and Gameplay settings are controlled by the host and synchronized to every player in multiplayer; players joining a game receive the host's settings.

<ins>**Automatic Productions:**</ins>

**Automatically manages your production facilities:**

- Enabled: Productions activate when inputs are available and deactivate when outputs reach the high output threshold

- Disabled: Manual control only (default)

Productions outside their scheduled months are never restarted by auto-management.
